# 🌤️ Weather App

A clean, responsive web application that displays real-time weather conditions(City-name, Temperature, Humidity and wind-speed) for any city in the world. Built with  HTML, CSS, and JavaScript.

#Features

- Search weather conditions for any city globally
- Displays current temperature
- Shows humidity and wind speed
- Real-time data pulled from the OpenWeatherMap API
- Responsive design — works on desktop and mobile

---

#Built With

- HTML5
- CSS3
- JavaScript
- [OpenWeatherMap API](https://openweathermap.org/api)

---

#Getting Started

#1. Clone the repository

```bash
git clone https://github.com/your-username/weather-app.git
cd weather-app
```

# 2. Get your API key

- Go to [https://openweathermap.org](https://openweathermap.org) and create a free account
- Navigate to **API Keys** in your dashboard
- Copy your key

# 3. Add your API key

Open `script.js` and replace the placeholder with your key:

```js
const API_KEY = "your_api_key_here";
```

# 4. Run the app

Just open `index.html` in your browser — no install or build step needed.
